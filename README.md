# ⚡ 台灣大學電機系學生網站 (NTUEE Student Portal)

這是一個專為台灣大學電機系學生打造的入口網站，使用 Python Django 框架開發。網站整合了系級重要公告、各系隊與學生團體的專屬分頁、動態行事曆，以及完善的角色權限控制系統 (RBAC)，讓系學會與各系隊負責人能夠自主管理所屬的內容。

## ✨ 核心功能 (Features)

* **📢 智慧分類公佈欄**
  * 支援「學生活動、校務行政、系上通知」等多重分類。
  * 支援自定義「標籤 (Tags)」過濾與搜尋功能。
* **🏀 系隊與團體專屬分頁**
  * 每個系隊擁有獨立的資訊頁面與專屬佈告欄。
  * **權限下放**：被指派為「管理員」的學生，可直接在前台編輯系隊簡介、發布公告與新增活動，無需進入系統後台。
* **📅 整合式動態行事曆**
  * 結合 FullCalendar 套件，視覺化呈現全系活動與系隊賽程。
* **🎓 靜態資源專區**
  * 統整大學部修業規定、137 學分計算方式與課程地圖，方便學生隨時查閱。

## 🚀 環境建置與啟動教學 (Installation & Setup)

本專案使用標準 Python 虛擬環境開發，請確保你的系統已安裝 Python 3。

### 1. 取得專案與建立虛擬環境
打開終端機，進入專案資料夾並建立 `venv`：
```bash
# 建立虛擬環境
python -m venv venv

# 啟動虛擬環境 (Linux / macOS)
source venv/bin/activate
```

### 2. 安裝相依套件
在啟動虛擬環境的狀態下，安裝 Django：
```bash
pip install django
```

### 3. 資料庫初始化
執行 Django 資料庫遷移，建立所需的資料表：
```bash
python manage.py makemigrations
python manage.py migrate
```

### 4. 建立最高權限管理員 (Superuser)
為了進入系統後台建立初始資料，請先建立一個管理員帳號：
```bash
python manage.py createsuperuser
# 依序輸入帳號 (例如: admin)、信箱(可留白) 與密碼
```

### 5. 啟動本機伺服器
```bash
python manage.py runserver
```
啟動後，請打開瀏覽器訪問：`http://127.0.0.1:8000/`

## 🎮 如何操作與測試權限邏輯 (Usage Guide)

為了完整體驗網站的權限控制功能，請依照以下步驟進行測試：

### Step 1: 建立基礎資料 (後台)
1. 進入後台：訪問 `http://127.0.0.1:8000/admin`，使用剛剛建立的 Superuser 登入。
2. **新增一般學生帳號**：在 `Users` 區塊，新增兩個帳號（例如 `b14901056` 與 `b14901057`）。
3. **新增標籤**：在 `Tags` 區塊，新增如「大一」、「活動」、「課程」等標籤。
4. **新增系隊並綁定權限**：在 `Teams` 區塊新增一個系隊（如「電機系羽」）。**重要：** 在 `Managers` 欄位中，選中 `b14901056` 賦予其該隊的管理權限。

### Step 2: 前台身分切換測試 (前台)
1. 回到首頁 `http://127.0.0.1:8000/`。
2. **一般學生視角**：點擊右上角「學生登入」，使用 `b14901057` 登入。點進「電機系羽」分頁，此時只能純瀏覽，**無法**發布公告或修改簡介。
3. **管理員視角**：登出後，改用 `b14901056` 登入。再次點進「電機系羽」分頁，畫面會自動出現**「🔧 管理員控制台」**，可直接在前台進行發佈公告、修改簡介與新增行事曆活動。
